# Terminal Shelf

O **Terminal Shelf** e uma aplicacao desktop para centralizar e organizar seu trabalho em terminal por projeto.

Em vez de abrir varias janelas soltas, voce monta um workspace unico com seus repositorios, cria sessoes dedicadas para cada contexto e alterna entre elas com rapidez.

## O que ele e

Um hub visual de terminal orientado a projetos.

Voce adiciona pastas de trabalho, organiza por grupos, abre terminais vinculados a cada projeto e acompanha tudo em uma interface unica, com foco em produtividade diaria.

## Para que e usado

- Trabalhar em varios projetos sem perder contexto
- Separar ambientes por cliente, produto ou frente de trabalho
- Alternar entre tarefas sem precisar reconfigurar terminais manualmente
- Manter uma visao clara do que esta rodando, pausado ou encerrado
- Reduzir friccao no dia a dia de desenvolvimento

## Principais features

- **Workspace por projetos**: cada terminal fica ligado a uma pasta especifica.
- **Grupos de projetos**: organize repositorios por area, time ou cliente.
- **Multiplos terminais por projeto**: crie threads separadas para build, servidor, testes, scripts etc.
- **Split view vertical e horizontal**: compare e use varios terminais lado a lado.
- **Reconexao de sessao**: reabra terminais fechados para continuar o fluxo de trabalho.
- **Status em tempo real**: acompanhe se cada sessao esta em execucao, inativa, fechada ou com erro.
- **Renomeacao de sessoes**: deixe cada terminal com um nome claro para facilitar navegacao.
- **Atalhos de produtividade**: abra splits e feche paineis rapidamente pelo teclado.

## Como usar no dia a dia

1. Adicione seu primeiro projeto (pasta local).
2. Se quiser, crie grupos para organizar os projetos.
3. Abra um terminal para o projeto selecionado.
4. Crie novos terminais quando precisar separar tarefas.
5. Use split view para acompanhar mais de uma sessao ao mesmo tempo.
6. Renomeie as sessoes para manter tudo facil de identificar.

## Para quem e

Ideal para devs que trabalham com:

- Monorepos ou varios repositorios ao mesmo tempo
- Rotina com muitos comandos recorrentes
- Context switch frequente entre tarefas e projetos
